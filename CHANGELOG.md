# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-08-03

- Add a standalone, local-only reverse proxy for Sub2API Responses traffic.
- Add runtime Fast ON/OFF switching without container restarts.
- Add Windows and POSIX installation, toggle, status, and uninstall helpers.
- Add strict request inspection, SSE streaming tests, health checks, and a
  local status endpoint.
- Add bilingual documentation, licensing, security guidance, and CI.
